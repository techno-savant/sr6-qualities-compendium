# SR6 Core Qualities

A Foundry VTT module for the `shadowrun6-eden` system.

65 positive and negative qualities from the Shadowrun 6th Edition Core Rulebook (positive-qualities and negative-qualities packs). The packs are filled when a GM opens a world: any missing quality is created by name, existing ones are left alone. Leveled qualities (Built Tough, Glass Jaw, Will to Live) keep their effect value in step with the level in the item name ("Built Tough 3" gives +3).

## Compatibility

- Foundry VTT 13 and 14 (verified on 14.369 in the manifest).
- Eden (`shadowrun6-eden`) 3.3.9 and 4.x. Item data in this module uses the older Eden item shape; Eden 4.x cleans it when the item is created.

## Install

This module is not in the Foundry package registry. Copy a pinned build (a tarball made from a git ref of this repository) into the `modules` folder of the Foundry data directory, or use the manifest URL in `module.json`, then enable it in the world.
